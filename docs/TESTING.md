## Target-machine acceptance still required

1. Open the app at desktop and mobile widths; verify typography, labels, focus states, no clipping and all navigation.
2. Verify actual WebGL rendering, orbit/zoom, equipment picking and state-driven animation. Disable WebGL and confirm the HTML workflow remains usable.
3. Enable a real webcam. Confirm local model loading, a face mesh, neutral-expression captures and valid quality measurements. Exercise no-face/multiple-face, poor lighting, movement, permission denial and camera unplugging. Confirm the camera indicator turns off after stop/navigation/capture.
4. Enroll three valid live captures under consistent conditions and repeat a live comparison. Confirm synthetic fixture history is excluded. Calibrate capture thresholds across camera aspect ratios and optics before making repeatability claims.
5. Complete the A–G demo sequence in a real browser. Run the provided Playwright suite; its backend database is disposable.
6. Disconnect internet while keeping the local server running. Reload routes and enable the local camera model. No core runtime request should leave localhost. External research links and the optional Swagger docs UI are not offline features.
7. Close and restart the local process. Confirm records/reminders/reports remain and queued transport resumes. No push notification should be claimed while the process is stopped.

The remaining checks are release validation, not evidence already obtained. Clinical validation, verified face identity, actual hardware integration, secure multi-user authentication, and local speech recognition are outside this implementation.
